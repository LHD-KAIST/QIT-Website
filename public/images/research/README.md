# Research figures

Drop research-area figures in **this folder**, named to match the `figure` field
of each area in `src/data/tags.json`.

Current expected filenames: `quantum-learning.jpg`, `nisq.jpg`, `metrology.jpg`.

The site replaces the placeholder with the real figure automatically. Until a
figure exists, a placeholder is shown.

**Tips:** landscape (~4:3) works best, at least ~800px wide, `.jpg` or `.webp`.
Remember to write a meaningful `figureAlt` for that area in `tags.json` (for
screen readers).

To upload on GitHub: open this folder → **Add file → Upload files** → drag the
image in → **Commit changes**.
